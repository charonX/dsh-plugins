# 架构重构 Playbook

适用于保持外部行为等价前提下的结构重组，重点严控破坏性回归与影响面蔓延。

1. **影响面与基线摸底** {#analyze} (`blast-radius`, `how`, 只读): 绘制下游调用方、接口契约、序列化格式与持久化结构影响图，锁定已有全绿基线测试。
2. **测试防护与小步重构** {#refactor} (`tdd`, 失败重试): 先补齐边界调用方与状态不变量测试，再分步提取公共逻辑与替换旧实现，每一步保持绿灯。
3. **独立等价性与风险审查** {#review} (`code-review`, 只读, 失败回退: refactor): 重点审查语义漂移、隐式副作用丢失、孤立死代码残留与命名一致性。
4. **全量门禁验证** {#verify} (`verify`, 失败回退: refactor): 运行全套单元测试、构建与真实运行表面，确认无遗漏引用或契约破坏。
5. **交付简报** {#ship} (`ship-pr`): 说明重构前后依赖对比、Door 类型与受影响调用方验证结果。
