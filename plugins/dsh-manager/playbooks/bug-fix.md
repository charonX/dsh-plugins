# 通用缺陷修复 Playbook

适用于明确故障现象或报错的定位修复流程，禁止跳过复现直接猜改。

1. **复现与盲区定位** {#reproduce} (`bug-fix`, 只读): 先稳定复现故障，顺调用链定位最早根因，并核查为什么现有测试未拦住该缺陷；同一假设连改 3 次失败立刻回退重检。
2. **补红灯与最小修复** {#fix} (`bug-fix`, `tdd`, 失败重试): 先补能稳定复现失败的回归测试（Red），再沿根因做最小修复使其变绿（Green），不顺手扩面重构。
3. **门禁与真实表面复验** {#verify} (`verify`, 失败回退: fix): 复跑回归测试、项目构建与真实验证表面，确认故障彻底消解且无副作用。
4. **独立审查** {#review} (`code-review`, 只读, 失败回退: fix): 核查边界条件、受影响调用方与异常恢复逻辑，不遗漏静默吞错或状态竞争。
5. **交付整理** {#ship} (`ship-pr`): 附带 Before/After 复现对比证据与回归半径说明，输出交付简报。
