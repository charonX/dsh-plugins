# 知识创作 Playbook

适用于直接在当前工作区沉淀文档、文章与知识库条目的多步创作与核查流程。

1. **资料调研** {#research} (`how`, 只读): 读取相关源码、配置、历史决策与参考资料，提取带准确 `file:line` 与版本号的客观事实，形成要点清单。
2. **草稿创作** {#draft} (`writing`, 失败重试): 结论先行、结构清晰地撰写文章或技术文档草稿，遵守目标知识库目录与时间规范。
3. **去水词与事实审校** {#review} (`writing`, 只读, 失败回退: draft): 清除 AI 空洞副词与模板过渡句，逐条核对文档中的符号名、命令、路径与实测证据，发现失实立即打回修改。
4. **定稿检查** {#verify} (`verify`): 检查链接可跳转、敏感信息脱敏与格式规范，确认无误后准备归档或提交。
