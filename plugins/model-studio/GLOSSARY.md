# 模型层工作室

本语境描述"一个网关如何被本机配置、被什么数据描述"。它存在的原因：同一个上游品牌可以有多条路由，
同一个网关可以用不同方言表达"思考开关"，而这两件事在代码与配置里长期共用一个词 provider。

## 语言

**网关 Gateway**：
上游那个 HTTP 端点服务，包括各类中转与自建推理服务。一个网关可以被多条路由指向。
_Avoid_: 供应商、provider

**供应商 Provider**：
上游品牌或目录条目（`models.dev` 的 `siliconflow`、已装 pi-ai 目录的 `deepseek`）。它描述"谁提供了模型"，不描述"本机怎么连它"。
_Avoid_: 网关、渠道

**路由 Route**：
本机的一份可调用配置单元：端点、协议、凭据引用、模型表。配置文档里写作 `providers.<id>`，此处的 id 就是路由标识。
_Avoid_: 供应商、provider 配置

**已装目录 Installed catalog**：
随 pi-ai 一起安装、开箱即可配置的供应商目录。它决定"官方添加供应商"能直接列出谁。
_Avoid_: 官方列表、内置供应商表

**预设目录 Preset directory**：
本插件维护的网关条目集合，用于把一条路由一次写完（端点、协议、密钥变量、兼容块、代表模型）。只收录已装目录之外的网关，且该过滤在运行时按目录判定，不靠构建期假设。
_Avoid_: 模板、供应商表

**预设 Preset**：
预设目录里的一条条目。

**方言 Dialect**：
一个网关表达"是否思考、思考多强"的线上约定，体现为字段名与取值形状。
_Avoid_: 思考模式、推理协议

**思考格式 thinkingFormat**：
方言在 harness 配置里的名字（`qwen`、`chat-template`、`openai` 等）。方言是事实，思考格式是这份事实的配置拼写。
_Avoid_: 思考模式

**兼容块 compat**：
一条路由（或其中一个模型）如何发请求的开关集合。它决定思考格式、系统消息角色名、输出上限字段等。
_Avoid_: 兼容配置、参数

**数据快照 Snapshot**：
构建期从 `models.dev` 拉取并裁剪后入库的那份供应商与模型事实。它在运行时不联网、不会自己更新。
_Avoid_: 缓存、数据库

**代表模型 Representative**：
一份预设里随路由一起写进去的、用于开箱对话的模型条目。它不等于该网关的全部模型。
_Avoid_: 默认模型、推荐模型

**扩展区 Extension area**：
官方页面内由插件贡献的那块界面，与官方内容之间有显式边界与归属标签。
_Avoid_: 插件页、自定义区
